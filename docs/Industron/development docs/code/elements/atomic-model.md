# Atomic model

## FASTSATT

- Atomnummeret er antall protoner.
- Et nøytralt atom starter med samme antall elektroner som protoner.
- Nøytrontall og standardisotop skal utledes av en felles stabilitetsregel.
- Positive og negative ioner oppstår ved å fjerne eller legge til elektroner.
- Ionets egenskaper og mulige bindinger skal beregnes, ikke deklareres per element.

## PLANLAGT beregningslag

1. Bygg nucleus-data fra atomnummer.
2. Velg beregnet standardisotop.
3. Fordel elektroner i det fiktive shell/orbital-systemet.
4. Finn valence-signatur.
5. Beregn energikostnad for mulige ion states.
6. Behold kun stabile eller tillatte ioner.
7. Utled atomradius, bindingstendens, metallicity, magnetisk tendens, reaktivitet og fargesignatur.

## Viktig designregel

Modellen skal være inspirert av virkeligheten, men den skal være intern konsistent med Industron-universet. Den skal ikke kopiere det ekte periodesystemet og deretter bare gi elementene nye navn.

## ÅPEN

- Shell-kapasiteter.
- Standardisotop-formel.
- Tillatt maksimal ioneladning.
- Hvordan tier påvirker energiskala uten å ødelegge atomidentiteten.
