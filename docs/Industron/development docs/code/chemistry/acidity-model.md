# Fiktiv acidity/basicity

## FASTSATT skala

- `0`: nøytral/reference.
- Positive verdier: stadig mer acidic.
- Negative verdier: stadig mer basic.

Dette er ikke ekte pH og bør få et eget internt navn senere.

## PLANLAGT beregning

Verdien kan utledes fra blant annet:

- charge distribution;
- binding polarization;
- ion stability;
- evne til å avgi/ta opp systemets proton-/charge-equivalent;
- solvent/context;
- temperature.

Neutralization-regler skal bevege kombinasjonen mot 0 og produsere gyldige salter/byproducts når kjemimodellen tillater det.
