# Industron

Dette er design- og overleveringspakken for **Industron**.

Industron er et selvstendig Minecraft-modprosjekt med et fiktivt periodesystem, automatisk materialfysikk, regelstyrt kjemi, genererte recipes, maskiner, casings, multiblocks og maintenance. Create skal brukes for enkelte funksjoner og integrasjoner, men skal ikke være fundamentet for hele systemet.

## Viktig status

Dokumentene er en blanding av **gjeldende implementasjon**, fastsatte designregler og framtidig roadmap. Faktisk prosjektkode er fasit for hva som er implementert. Assembly-systemet er allerede implementert og dokumenteres kanonisk i `development docs/code/recipes/assembly-recipes.md`; eksempler i eldre `to do/`-filer kan være historiske målnotater og skal ikke overstyre den kanoniske guiden.

Start her:

1. `development docs/README.md`
2. `development docs/preferences/README.md`
3. `development docs/code/README.md`
4. `development docs/to do/README.md`

Prosjektnavnet er **Industron**.
